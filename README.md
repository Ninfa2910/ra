# RA - Partes de la computadora

Proyecto preparado para GitHub Pages.

## Publicación rápida
1. Cree un repositorio nuevo en GitHub.
2. Suba TODOS los archivos y carpetas de este paquete a la raíz del repositorio.
3. En el repositorio vaya a Settings > Pages.
4. En Build and deployment seleccione Deploy from a branch.
5. Seleccione la rama `main` y la carpeta `/ (root)`.
6. Guarde. GitHub mostrará la dirección HTTPS pública.
7. Abra esa dirección en el celular y pulse “INICIAR REALIDAD AUMENTADA”.

No abra `ar.html` mediante `file:///`, porque el navegador puede bloquear la cámara.

## Archivos
- index.html: portada
- ar.html: cámara y experiencia RA
- marcadores_imprimir.html: hoja de marcadores
- patterns/: patrones AR.js
- marcadores/: imágenes imprimibles
